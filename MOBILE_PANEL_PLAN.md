# План: панель на главной (мобильная версия)

Макеты: https://claude.ai/artifact/KNpf1xWjWq8Vxo5Wt9TgYb

Работаем строго итеративно: шаг → сборка → проверка руками → правки → следующий шаг.
Десктоп в рамках этого плана не трогаем.

## Как устроено сейчас

- Панель — класс `Sidebar` в `static/js/components/sidebar/sidebar.js`, стили в `static/css/sidebar.css`. Создаётся лениво при первом выборе станции/поезда и закрывается, когда выбора нет.
- На мобильном высота фиксированная: 50vh для станции, 35vh для поезда (класс `minimized`). Пользователь размером управлять не может, ручки нет.
- Содержимое собирается строками в `static/js/components/sidebar/SidebarContent.js` (типы `station` и `route`).
- Точки «?» открывают попап MapLibre, а не панель (`static/js/components/poi/poi.js`).
- Граница мобильной версии: JS — `innerWidth < 768` (`DESKTOP_THRESHOLD`), CSS — `max-width: 768px`. На ровно 768px расходятся — поправить попутно.

## Шаги

- [x] **1. Панель всегда на экране.**
  На мобильном панель создаётся сразу при загрузке и не исчезает. Когда ничего не выбрано — заголовок «Поезда Грузии» и временная заглушка, крестика нет (как на макете 1). У станции и поезда крестик остаётся (макеты 2 и 3), но теперь он сбрасывает выбор и возвращает к состоянию по умолчанию, а не прячет панель.
  Высота панели в этом шаге одна для всех состояний, как на макете 1 (верх панели примерно на середине экрана). Отдельные `minimized` для поезда убираем — размеры по состояниям появятся в шаге 5.
  *Проверить:* панель видна при открытии главной; выбор станции → крестик → снова панель по умолчанию; поезд и «Назад» работают как раньше.

- [x] **1б. Каркас панели как на макете.**
  Переделать оболочку панели: фон, тень вместо рамки, скругление 16px, шапка без серого градиента, размер заголовка, отступы, крестик 44×44, цвета (текст #15181C, вторичный #5B636D, разделители #E3E6EA). Ручка-полоска сверху — пока только как элемент оформления, перетаскивание в шаге 2. Содержимое состояний внутри панели не трогаем — оно в шагах 3–4, 6, 7.
  Шрифт оставляем шрифтом сайта (на макетах Inter, но смена шрифта — отдельное решение, не про панель).
  Делаем до шага 2, чтобы жесты отлаживать сразу на финальном каркасе.
  *Проверить:* панель по умолчанию, станция и поезд выглядят в новой оболочке; содержимое и поведение не сломались.

- [x] **2. Ручка и управление размером.**
  Ручка-«полоска» сверху. Панель тянется пальцем и при отпускании встаёт в одно из трёх положений: свёрнута (виден только заголовок), на полэкрана, развёрнута почти до шапки. Тап по ручке переключает положения. Прокрутка содержимого — только в развёрнутом состоянии, чтобы не конфликтовать с перетаскиванием.
  *Проверить на реальном телефоне:* перетаскивание, положения, прокрутка внутри, жесты карты под панелью.

- [x] **2б. Панель сворачивается, когда пользователь двигает карту.**
  Перетаскивание, зум или вращение карты пальцем сворачивают панель до минимума (виден только заголовок). Обратно сама не разворачивается — пользователь тянет ручку или выбирает объект. Движения карты, запущенные кодом (`fitBounds`, `flyTo` при выборе станции/поезда), панель не трогают — отличаем по `originalEvent` у событий MapLibre.
  *Проверить:* двигаю карту — панель свернулась; выбираю станцию — карта перелетает, панель не свернулась.

- [x] **3. Содержимое по умолчанию, часть 1: маршруты** (макет 1).
  Поезда сгруппированы в маршруты по паре конечных станций (как `group_lines` в GTFS). Порядок — по ведущему городу из `LINE_NAME_CITY_PRIORITY` (копия в `static/js/components/route/routeLines.js`), внутри — по наименьшему номеру. Карточка: название, номера, строки по направлениям с временем отправления. Без деления на «Дальние»/прочие, без блока «Сейчас не ходят», без строки «длительность · тип поезда». Карточки пока не кликабельные.

- [x] **4. Содержимое по умолчанию, часть 2** (макет 1б).
  Чипы станций, «Что нового», ссылки «О проекте» и «Источники данных».
  Станции: список из макета с названиями из данных; тап по чипу — то же, что клик по станции на карте; «Все станции» — страница «Станции» в том же окне.
  «Что нового» (до 3 записей карточками, полный текст записи) и ссылка «О проекте» рендерятся в Hugo в `<template id="sidebar-default-footer">` в `layouts/index.html`, JS вставляет его в панель. В ka блока «Что нового» нет (раздела нет на ka). «Источники данных» убраны.
  Заголовки разделов «Маршруты», «Станции», «Что нового» — как на макете «вся страница», без капса.

- [x] **5. Положение панели и карта.**
  Каждое состояние открывается в своём положении: станция — на полэкрана, поезд — ниже, «?» — небольшое.
  В частности: если панель развёрнута полностью и пользователь выбирает поезд (маршрут), панель опускается наполовину, чтобы маршрут был виден на карте — как было до шага 2.
  Сделано: при выборе станции или поезда (смене показанного) панель встаёт на полэкрана из любого положения; отступ карты снизу (`getBoundsPadding`) = высота панели на полэкрана. Отдельное, более низкое положение для поезда не делали. Карта учитывает высоту панели (`map.setPadding`), чтобы выбранная станция/маршрут не прятались под панелью.

- [ ] **6. Точки «?» в панели вместо попапа** (макет 4).
  Только на мобильном (на десктопе — попап, как раньше). Заголовки точек дописаны в `poi.js` (ka — показать носителю). Без плашки «не ходят с …» и ссылки «Ближайшие поезда» — до появления данных.

- [ ] **7. Новый вид станции и поезда** (макеты 2 и 3).
  Станция: грузинское название, описание, бейджи номеров. Поезд: «‹ <станция>» вместо «Назад к списку», строка «время · длительность · периодичность», полный список остановок вместо только конечных.

- [ ] **7б. Вернуться к вопросу клика по карточке маршрута.**
  В шаге 3 карточки маршрутов сделаны некликабельными. Решить, что происходит при тапе: выбор поезда на карте (тап по времени отправления), переход на страницу направления (`/directions/...`, как `route_url` в GTFS) или что-то ещё.

- [ ] **8. Доводка.**
  Кнопки масштаба при развёрнутой панели, safe-area на iPhone, аппаратная кнопка «Назад» на Android.
